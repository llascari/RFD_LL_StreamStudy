# Credits

**Human-prompted. LLM-implemented.**

This repository is essentially a prompting exercise. The human maintainer (llascari) supplied the
idea, scope, requirements, review notes and course corrections. The implementation — code, tests,
documentation, CI configuration and screenshots — was generated by an LLM agent running in
[LM Studio Bionic](https://lmstudio.ai/).

- **Implementation model:** DeepSeek V4.1 Flash (`deepseek-ai/DeepSeek-V4.1-Flash`)
- **Harness:** [LM Studio](https://lmstudio.ai/) Bionic — LM Studio's agentic coding harness,
  running the model locally through the desktop app's agent loop
- **Human role:** prompter, reviewer, decision-maker
